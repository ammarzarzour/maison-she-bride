# Maison She Bride

متجر أزياء إلكتروني تجريبي مع واجهات المتجر والبائع والإدارة، متصل بـ Supabase.

## صفحات المشروع

- **نسخ ملخص السلة دون صلاحية الحافظة:** إذا منع المتصفح النسخ التلقائي، تحدد الواجهة نص ملخص السلة التجريبي محلياً وتضع التركيز عليه للنسخ اليدوي؛ لا ترسل طلباً أو بيانات إلى الخادم. تغطية في `tests/storefront-storage.cjs`.

- **إزالة المنتج من السلة بضغطة واحدة:** أضيف زر إزالة مستقل لكل منتج في سلة العرض، مع تسمية واضحة بالعربية والإنجليزية لقارئات الشاشة، وتحديث فوري للعدد والإجمالي والتخزين المحلي دون أي طلب أو دفع. اختبار انحدار في `tests/storefront-storage.cjs`.
- `index.html`: المتجر، البحث، الأقسام، المفضلة المحفوظة على الجهاز، فرز المنتجات حسب السعر والاسم، السلة، العربية والإنجليزية، وتبديل العملة. تعرض الواجهة 24 منتجاً في الصفحة مع أزرار تنقل ثنائية اللغة وتعيد الصفحة الأولى عند تغيير البحث أو التصنيف أو الفرز.
- **تأكيد استيراد المسودة:** إذا كانت حقول المنتج الحالية تحتوي عملاً غير محفوظ أو صورة مختارة، تعرض لوحة التاجر تأكيداً مترجماً قبل استبدالها بمسودة JSON مستوردة. الإلغاء يُبقي العمل كما هو، ويُعاد التحقق من الجلسة وسباق الاستيراد بعد التأكيد. لا تتغير بيانات الخادم؛ اختبارات `tests/seller-draft-import.cjs`.
- **إدارة المسودة المحلية للتاجر:** يمكن مسح حقول المنتج والصورة والمعاينة محلياً بزر ثنائي اللغة، مع إبطال أي قراءة ملف JSON معلقة. إذا عدّل التاجر حقول المنتج أثناء استيراد ملف، تبقى تعديلاته هي الأحدث ولا تُستبدل بنتيجة الاستيراد المتأخرة. لا تُرسَل بيانات إلى Supabase ولا تُفعّل الكتابة؛ يغطي `tests/seller-draft-import.cjs` ضوابط الحماية.
- `seller.html`: واجهة التاجر للمراجعة والقراءة بالعربية والإنجليزية، مع اكتشاف لغة الجهاز واختيار يدوي محفوظ (`msb_seller_lang`) واتجاه RTL/LTR. تعرض ملخص مخزون المسودات والمنتجات المنشورة والمنخفضة أو النافدة، وتترجم الملخص وحالات المنتجات عند تبديل اللغة دون إعادة جلب البيانات. عمليات الكتابة غير مفعلة إلى حين مراجعة صلاحيات قاعدة البيانات.
- **تعافي تصدير الجرد عند منع التنزيل:** إذا منع المتصفح إنشاء ملف CSV أو النقر على رابط التنزيل، تعرض لوحة التاجر رسالة خطأ مترجمة بدلاً من استثناء غير معالج، مع تنظيف الرابط المؤقت وعنوان Blob حتى عند فشل التنزيل. لا يُرسَل أي ملف إلى الخادم ولا تُعدَّل بيانات المنتجات؛ يغطي `tests/seller-inventory-export.cjs` وجود مسارات التعافي والتنظيف.
- `admin.html`: لوحة الإدارة ثنائية اللغة (العربية والإنجليزية) مع اختيار لغة النظام تلقائياً وتبديل يدوي محفوظ (`msb_admin_lang`) واتجاه RTL/LTR. تُترجم حالات المتاجر والمنتجات والطلبات، ويظل تحرير حقول الشحن غير المحفوظ في ذاكرة الصفحة عند تبديل اللغة، دون طلب خادم إضافي. عند رفض جلسة الإدارة بالرمزين HTTP 401/403 تُخفى بيانات اللوحة وتُمسح القيم غير المحفوظة محلياً. لا تمنح ترجمة الواجهة أي صلاحيات جديدة.
- **منع سباق تحديث الجرد ضمن جلسة التاجر نفسها:** إذا بدأ تحميلان متداخلان للمنتجات، لا يُسمح للتحميل الأقدم بإعادة عرض جرد سابق بعد اكتمال الأحدث، أو بعرض نتائج مؤقتة قبل اكتمال الأحدث. يُحافَظ على حماية تسجيل الخروج، وتُغطى الحالات في `tests/seller-refresh-race.cjs`، دون تعديل أي بيانات أو صلاحيات في Supabase.
- **حماية جلسة التاجر من استجابات الشبكة المتأخرة:** بعد تسجيل الخروج أو الانتقال إلى حساب آخر، لا تستطيع استجابة قديمة لتسجيل الدخول أو قراءة المتجر أو الأقسام أو المنتجات إعادة عرض بيانات الحساب السابق أو إعادة ملء الذاكرة المؤقتة. تُمسح تفاصيل المخزون والأقسام من الصفحة عند الخروج. تُمنع أيضاً رسائل الخطأ المتأخرة من طمس رسالة الخروج. لا يغير ذلك صلاحيات Supabase أو يفعّل كتابة المنتجات؛ اختبار `tests/seller-session-race.cjs`.
- **حماية لوحة الإدارة من استجابات الشبكة المتأخرة:** بعد تسجيل الخروج أو انتهاء الصلاحية لا تعيد استجابات التحميل القديمة إظهار البيانات، ولا تتيح استجابة HTTP 401/403 تخص جلسة سابقة إبطال جلسة أحدث. عند تداخل تحديثين، لا تتجاوز نتيجة أقدم أحدث بيانات تم تحميلها. لا تلغي هذه الحماية أي إجراء تعديلي أُرسل بالفعل إلى الخادم؛ فهي تمنع فقط إعادة عرض حالة محلية منتهية.
- **سلامة بيانات الكتالوج:** لا تُعرض دفعة تحتوي سعراً غير رقمي أو مخزوناً غير صحيح؛ تُظهر الواجهة خطأ بدلاً من سعر `NaN` أو كمية مضللة. الاختبارات في `tests/catalog.cjs` تغطي الحالات غير الصالحة.
- التحقق من أسعار وكميات مخزون الكتالوج يرفض القيم الفارغة و`null` والقيم المنطقية بدلاً من تحويلها ضمنياً إلى صفر؛ يغطي `tests/catalog.cjs` هذه الحالات.
- تُرفض كذلك مصفوفات JSON والكائنات الواردة في حقول السعر والمخزون حتى إن أمكن تحويلها رقمياً في JavaScript، مع اختبارات انحدار لهذه الحالات.
- تقبل الأسعار والمخزون المرسلة كنصوص أرقام عشرية عادية (مثل `12.50` و`2`) فقط، وترفض المسافات المحيطة بالأرقام والصيغ التي يحوّلها JavaScript ضمنياً مثل ` 12` و`2 ` و`0x10` و`1e3` و`+2`؛ دون تغيير أي بيانات في Supabase.
- تُرفض أسعار USD الضخمة التي تتسبب بتجاوز نطاق الأرقام عند تحويلها بسعر العرض التجريبي لليرة السورية (`120`)، لتجنّب إظهار `Infinity` في بطاقات المنتجات أو السلة؛ هذا ليس تحققاً من أسعار الصرف الحقيقية.
- يتحقق محمّل الكتالوج كذلك من أن حاصل ضرب سعر الوحدة في كامل المخزون ثم معامل العرض التجريبي لليرة السورية يظل عدداً محدوداً، لأن سعراً صالحاً منفرداً قد ينتج إجمالياً غير صالح عند ضربه في كمية كبيرة. يغطي `tests/catalog.cjs` الحالتين السليمة وغير السليمة؛ لا يتغير مخزون Supabase ولا تُنفّذ معاملات.
- يُرفض أي منتج بمعرّف فارغ أو مؤلف من مسافات بيضاء فقط، لحماية الربط بين بطاقة المنتج والسلة؛ تغطي الاختبارات هذه الحالات.
- المنتجات المنشورة تحتاج اسماً غير فارغ بالعربية والإنجليزية؛ إذا احتوى رد الكتالوج على عنوان ناقص أو غير نصي، يُرفض الرد بأكمله بدلاً من عرض اسم فارغ أو `undefined`. أُضيفت حالات اختبار لذلك.
- أسماء الأقسام كذلك يجب أن تكون نصوصاً غير فارغة بالعربية والإنجليزية؛ يرفض محمّل الأقسام النتائج غير المكتملة، وتغطي اختبارات `tests/categories-pagination.cjs` الأسماء المفقودة والفارغة.
- **تحمّل انقطاع القراءة المؤقت:** يحاول `catalog.js` إعادة طلب صفحات القراءة فقط عند أخطاء HTTP 408/429/500/502/503/504 أو أخطاء الشبكة وانتهاء المهلة، بحد أقصى ثلاث محاولات وتأخير قصير 200 ثم 500 ميلي ثانية. لا يعيد المحاولة عند أخطاء الصلاحيات 401/403 أو بيانات JSON التالفة (بما فيها أخطاء TypeError أثناء قراءة جسم الاستجابة)، ولا يرسل أي كتابة أو دفع. إذا فشلت المحاولات تُخفى النتائج الجزئية وتظهر رسالة خطأ. تغطي `tests/catalog-retry.cjs` هذا السلوك.
- `catalog.js`: قراءة المنتجات والأقسام من Supabase على صفحات ثابتة من 100 عنصر حتى 1000 لكل نوع، مع رفض بيانات الأقسام المكررة أو الناقصة والنتائج الجزئية، وطلب تحقق إضافي عند اكتمال الحد. المنتجات: مع رفض النتائج الجزئية إذا فشلت صفحة لاحقة أو تكررت معرّفات المنتجات بين الصفحات أو وصلت بيانات ناقصة. يتحقق الكود بطلب إضافي محدود من اكتمال الكتالوج عند وجود 1000 منتج بالضبط؛ إذا تجاوز العدد 1000 يعرض خطأ بدلاً من إخفاء المنتجات الزائدة. تقسيم العرض إلى صفحات هو تقسيم داخل المتصفح فقط؛ ما زال جلب البيانات يقتصر على 1000 منتج، ويلزم ترقيم صفحات على مستوى الخادم للكتالوجات الأكبر. تُرفض كذلك الاستجابات التي تتجاوز حجم الصفحة المطلوب، لتجنب تخطي المنتجات.
- `sanad-preview.html` و`sanad-demo.js`: نموذج أولي لسند سوريا ضمن الاستضافة الحالية مؤقتاً؛ دليل خدمات ثنائي اللغة والبحث ومحاكاة إنشاء طلبات وهمية ومتابعة حالتها.
- **سلامة معرّفات الطلبات الوهمية:** يرفض النموذج السجلات المحلية المكررة بالمعرّف، ويولّد مرجعاً مختلفاً لكل طلب جديد حتى إذا تكررت قيم الساعة والعشوائية؛ لتجنب تحديث أو حذف عدة طلبات وهمية بسبب تصادم المعرّفات. اختبار الانحدار في `tests/sanad.cjs`، دون شبكة أو بيانات حقيقية.
- `sanad-admin-preview.html` و`sanad-admin-demo.js`: لوحة متابعة تجريبية باللغتين لعرض الطلبات الوهمية من نفس المتصفح، إحصائيات الحالات وتحديثها أو حذفها محلياً. **ليست لوحة إدارة محمية ولا خدمة حكومية** ولا تُستخدم معها بيانات أشخاص حقيقية. لا يوجد تسجيل دخول أو إرسال طلبات أو بيانات إلى الخادم.
- `backend/`: ملفات قاعدة البيانات.
- `tests/smoke.cjs`: فحص JavaScript وصفحات الموقع الأساسي وسند سوريا وروابط الانتقال المختصرة للنموذج.
- `tests/storefront.cjs`: اختبار سلوك المفضلة والفرز واستعادة السلة، وتقسيم المنتجات إلى صفحات، وحدود التنقل وإعادة ضبطه عند البحث أو الفرز.
- `tests/storefront-preferences.cjs`: اختبار استعادة اللغة والعملة من إعدادات المتصفح، ورفض القيم المخزّنة غير الصالحة ومنع عرض `NaN`، ودعم اتجاه العرض العربي والإنجليزي.
- `tests/storefront-storage.cjs`: اختبار استعادة السلة من بيانات محلية تالفة أو غير صالحة، وحماية معرّفات العناصر، والتعامل مع منع التخزين المحلي دون تعطّل السلة والمفضلة.
- `tests/seller-stock.cjs`: اختبار عرض ملخص المخزون للتاجر من بيانات وهمية، ومنع تعديل المخزون أو إنشاء المتاجر والمنتجات عندما تكون صلاحيات الكتابة غير مفعلة.
- **أقسام التاجر:** تُقرأ الأقسام بالعربية والإنجليزية على صفحات من 100 عنصر حتى 1000، مع ترتيب ثابت والتحقق من المعرّفات والأسماء وعدم التكرار. عند فشل صفحة أو تجاوز الحد لا تظهر خيارات ناقصة أو قديمة، وتُهمل الاستجابات المتأخرة بعد تسجيل الخروج. اختبار `tests/seller-categories-pagination.cjs`، دون تغيير صلاحيات Supabase أو تفعيل إنشاء المنتجات.
- `tests/seller-language.cjs`: اختبار الواجهة ثنائية اللغة للتاجر، التبديل التلقائي واليدوي، حفظ اللغة، تعريب حالات المخزون، وعدم إعادة الاتصال بقاعدة البيانات عند تبديل اللغة.
- `tests/admin-language.cjs`: اختبار لوحة الإدارة بالعربية والإنجليزية ببيانات محاكاة، حفظ اختيار اللغة، عدم إرسال طلبات أثناء التبديل، الاحتفاظ بتحرير الشحن محلياً، ومسح بيانات الجلسة بعد HTTP 403.
- `tests/admin-session-race.cjs`: محاكاة انتهاء الجلسة وتسجيل الخروج في أثناء طلبات API متأخرة، والتحديثات المتداخلة، واستجابات 401/403 من جلسة قديمة، وسباق تسجيل الدخول، دون الاتصال بحسابات أو بيانات حقيقية.
- `tests/storefront-safety.cjs`: اختبار منع إدراج وسوم HTML أو خصائص غير مقصودة ضمن أسماء الأقسام وأزرار السلة في اللغتين.
- `tests/categories-pagination.cjs`: اختبار ترقيم صفحات الأقسام حتى حد 1000، ومنع تكرار المعرّفات أو الأسماء التقنية (slug) أو قبول أقسام ناقصة أو استجابات جزئية. يشمل أيضاً اختبار استجابة أكبر من الحد المطلوب.
- `tests/live-categories.cjs`: اختبار عرض أسماء الأقسام الفعلية من Supabase بالعربية والإنجليزية، والتصفية، وتحديث القائمة عند تغيّر الأقسام.
- `tests/catalog-retry.cjs`: اختبار محاولات قراءة Supabase المحدودة للأخطاء المؤقتة، وعدم إعادة المحاولة عند أخطاء الصلاحيات أو الاستجابة التالفة.
- `tests/catalog-images.cjs`: اختبار قبول روابط صور المنتجات HTTPS فقط، ورفض بيانات الصور غير الصحيحة قبل عرض الكتالوج.
- يتحقق محمّل صور المنتجات أيضاً من أن ترتيب الصورة `position` قيمة عددية صالحة أو نص رقمي غير فارغ، ويرفض المصفوفات والكائنات والقيم المنطقية والنصوص البيضاء؛ تُعامل القيمة `null` أو الحقل الغائب كترتيب افتراضي صفر للتوافق مع البيانات السابقة.
- `tests/catalog-refresh.cjs`: اختبار تحديث الكتالوج عند فشل جلب المنتجات أو الأقسام، وإخفاء البيانات القديمة مؤقتاً مع الحفاظ على السلة، ثم نجاح إعادة المحاولة.
- `tests/sanad.cjs` و`tests/sanad-admin.cjs`: اختبار تفاعلي لمحاكاة الطلبات الوهمية ولوحة متابعتها، والتحقق من بقاء البيانات محلياً وعدم وجود اتصال شبكي.
- `.github/workflows/smoke.yml`: تشغيل الاختبارات عند تحديث الفرع الرئيسي أو فتح Pull Request.
- `tests/ci-coverage.cjs`: يتحقق آلياً من تسجيل كل ملف اختبار `tests/*.cjs` مرة واحدة بالضبط ضمن GitHub Actions، ويكشف الملفات المفقودة أو المسارات القديمة. يُنفّذ أولاً في CI؛ لا يغني عن نجاح بقية الاختبارات.

## فتح نموذج سند سوريا

- رابط النموذج المختصر على GitHub Pages: `https://ammarzarzour.github.io/maison-she-bride/sanad/`
- رابط لوحة المتابعة الوهمية: `https://ammarzarzour.github.io/maison-she-bride/sanad/admin.html`
- المساران داخل `sanad/` يعيدان توجيه المتصفح إلى صفحات النموذج الأصلية، ويوفران رابطاً يدوياً عند تعطيل التحويل التلقائي.
- النموذج **غير حكومي وغير صالح للطلبات الحقيقية**؛ البيانات الوهمية محلية في المتصفح. لا توجد مصادقة رسمية أو مدفوعات.
- نشر GitHub Pages مستقل عن نجاح اختبارات GitHub Actions؛ يجب التحقق من نتيجة مهمة `pages build and deployment` ومن فتح الرابط على متصفح فعلي. لا يوجد مستودع GitHub منفصل لسند بعد.

## تحديث التجربة الآمنة (Maison She Bride وSanad Syria)

- **متجر Maison She Bride:** أُزيلت حقول الاسم والهاتف وعنوان الشحن وخيارات الدفع الوهمية من نافذة السلة التجريبية، واستُبدلت بمعاينة نصية للمنتجات والكميات وإجمالي العرض، ثنائية اللغة ومتوافقة مع العملة المختارة. يمكن نسخ الملخص عبر الحافظة عندما يدعمها المتصفح، أو تحديد النص ونسخه يدوياً إذا منع النسخ. لا تُنقل البيانات ولا يُنشأ طلب أو معاملة مالية، والأسعار وأسعار الصرف للتجربة فقط.
- لا يُسمح بنسخ ملخص سلة فارغة أو في أثناء تعذر تحميل الكتالوج، ويُحدّ عدد القطع حسب مخزون الكتالوج المحمّل قبل إنتاج الملخص. العناوين تُطبع نصياً دون تضمين HTML، وتُزال أسطر العنوان غير المتوقعة للحفاظ على وضوح الملخص.
- **سند سوريا:** تفضيل اللغة للواجهة الخدمية يقبل `auto` أو `ar` أو `en` فقط، ويعود إلى لغة الجهاز عند فساد القيمة المخزنة أو حظر الوصول إلى التخزين المحلي. يظل التبديل اليدوي يعمل داخل الصفحة عند تعطيل الحفظ. لا تزال الطلبات وهمية ومحلية، ولا توجد حسابات رسمية أو رفع وثائق.
- اختبارات انحدار: `tests/cart-demo-quote.cjs` و`tests/sanad-language.cjs` ضمن فحوص GitHub Actions.

## تحديث جرد التاجر (قراءة فقط)

- زر «تحديث الجرد / Refresh inventory» يعيد قراءة المنتجات من Supabase دون أي تعديل عليها. يُعطّل أثناء التحميل، ويمسح بيانات الجرد والتصدير القديمة قبل إعادة الجلب حتى لا تظهر نتائج جزئية على أنها كاملة.
- عند تعذّر التحديث تظهر رسالة خطأ، ويمكن إعادة المحاولة؛ تُهمل نتائج المحاولات الأقدم إذا بدأت قراءة أحدث أو تغيرت جلسة التاجر. اختبار `tests/seller-inventory-refresh.cjs` مسجل في CI.

## ترتيب جرد التاجر (قراءة فقط)

- يمكن ترتيب قائمة الجرد المحمّلة بالكامل حسب المخزون تصاعدياً أو تنازلياً أو اسم المنتج بلغة العرض، مع الاحتفاظ بالترتيب الافتراضي للأحدث. يعمل الترتيب محلياً بعد تطبيق البحث والتصفية دون تغيير قاعدة البيانات أو ترتيب ملف CSV الكامل.
- الاختبار `tests/seller-inventory-sort.cjs` مضاف إلى فحوص GitHub Actions.

## تصفية جرد التاجر (قراءة فقط)

- بعد تحميل الجرد كاملاً، يمكن البحث باسم المنتج بالعربية أو الإنجليزية أو المعرّف، وتصفية المنتجات بحسب الحالة أو انخفاض المخزون (1–3) أو نفاده (0). تعرض الواجهة عدد النتائج من إجمالي الجرد.
- إحصاءات الجرد وملف CSV تبقى شاملة لكل منتجات التاجر، ولا تتأثر بتصفية العرض. البحث محلي ولا يرسل الكلمات المدخلة إلى الخادم، ويتوقف عند انتهاء الجلسة أو إعادة تحميل البيانات.
- الاختبار `tests/seller-inventory-filters.cjs` ضمن GitHub Actions.

## تصدير جرد التاجر (قراءة فقط)

- بعد تسجيل دخول تاجر معتمد وتحميل قائمة المنتجات كاملة بنجاح، يمكن تنزيل CSV محلي يحتوي معرّف المنتج، اسميه بالعربية والإنجليزية، سعر USD، المخزون والحالة. لا يحتوي الملف على بيانات العملاء أو كلمات المرور ولا يرسل بيانات إلى خدمة تصدير.
- زر التصدير معطّل قبل اكتمال الجلب وعند بدء التحديث أو تسجيل الخروج؛ لا يُصدّر نتائج جزئية أو قديمة. تُحمى خلايا CSV من الصيغ التي تبدأ بعلامات تشغيل جداول البيانات، ويُستخدم UTF-8 BOM لدعم العربية. الاختبار `tests/seller-inventory-export.cjs` ضمن CI.
- لا يُعد هذا تمكيناً لكتابة المنتجات أو تعديل المخزون، ولا يشمل الدفع أو الطلبات الحقيقية.

## حالة التشغيل

**الموقع ليس جاهزاً لاستقبال مبيعات حقيقية.**

- **اكتشاف المنتجات عبر البحث:** يبحث المتجر محلياً في أسماء المنتجات ووصفها بالعربية والإنجليزية، وكذلك أسماء الأقسام باللغتين، مع تطبيق تطبيع النص العربي واللاتيني الموجود. تُجلب الأوصاف من الكتالوج المنشور للبحث فقط ولا تُعرض بيانات شخصية أو تُرسل استعلامات بحث إلى الخادم؛ اختبار `tests/storefront-search.cjs`.
- البحث متعدد الكلمات يطابق جميع الكلمات بغض النظر عن ترتيبها، حتى عند توزعها بين الاسم والوصف والقسم وباللغتين العربية والإنجليزية (مثل `silk wedding` أو `bridal حرير`). يظل البحث محلياً ولا يرسل النص إلى الخادم؛ اختبار `tests/storefront-search.cjs`.
- البحث في المتجر يدعم اختلاف كتابة الألف والهمزات والياء/الألف المقصورة والتاء المربوطة، ويتجاهل التشكيل والتطويل العربي، ويبحث دون حساسية لحالة الأحرف أو التشكيل اللاتيني (مثل Crème/creme). هذه مطابقة نصية محلية وليست بحثاً ذكياً أو بحثاً في الخادم؛ اختبار `tests/storefront-search.cjs`.
- الكتالوج يعرض المنتجات المنشورة المتاحة من قاعدة البيانات؛ إذا كانت قاعدة البيانات خالية فلن تظهر منتجات. تظهر فلاتر الأقسام وأسماؤها المترجمة من بيانات Supabase الفعلية بعد نجاح التحميل، بدلاً من قائمة الأقسام الثابتة.
- إذا تعذّر تحميل المنتجات أو الأقسام، تُخفى البطاقات القديمة وتظهر رسالة فشل بدلاً من عرض معلومات مخزون قد تكون قديمة؛ تظل السلة التجريبية محفوظة على الجهاز حتى إعادة المحاولة.
- إذا أشار منتج إلى قسم غير موجود في نتيجة الأقسام، يرفض المتجر عرض الكتالوج بدلاً من تصنيفه خطأ ضمن «الكل»؛ تغطي اختبارات تحديث الكتالوج هذه الحالة.
- واجهة الكتالوج ترمّز النصوص غير الموثوقة من الأقسام ومعرّفات المنتجات عند إدراجها في HTML، بما يشمل أزرار السلة.
- روابط الصور التي تحتوي مسافات داخلية أو محارف فراغ Unicode أو شرطات مائلة عكسية تُرفض قبل أن يعيد المتصفح تفسيرها أو ترميزها؛ يغطي `tests/catalog-images.cjs` ذلك. لا تُعدل الصور المخزنة في Supabase.
- صور المنتج: يتحقق المحمّل من عدم تكرار ترتيب الصور ضمن المنتج، ويرفض أكثر من 30 صورة في سجل واحد؛ لا يعرض صفحة منتجات تحتوي بيانات صور غير متسقة. يغطي ذلك `tests/catalog-image-gallery.cjs`.
- يتحقق المحمّل من ترتيب صور المنتجات بصيغة عدد صحيح غير سالب أو نص رقمي عشري قياسي فقط؛ يرفض صيغ الأسس والإشارات والمسافات والأصفار البادئة (مثل `01`) والأرقام خارج النطاق الآمن، بدلاً من تحويلها ضمنياً. يغطي ذلك `tests/catalog-images.cjs`.
- معرض صور المنتجات: يعرض المتجر كل صور المنتج الصالحة حسب ترتيبها من قاعدة البيانات، مع أزرار مرقمة قابلة للاستخدام بلوحة المفاتيح وتسميات عربية/إنجليزية وحالة `aria-pressed` للصورة المختارة. يظل اختيار الصورة خلال الفرز وتبديل اللغة وإعادة رسم الصفحة، ولا يُخزن تاريخ التصفح؛ ويعود للصورة الأولى عند تحديث الكتالوج. لا يُنشئ طلبات أو مدفوعات. اختبار `tests/storefront-gallery.cjs`.
- عند تعذّر تحميل صورة منتج خارجية بعد نجاح قراءة بيانات الكتالوج، تُخفى الصورة المعطوبة ويظهر رمز المنتج البديل بدلاً من أيقونة صورة مكسورة. يستطيع الزائر اختيار صورة أخرى من المعرض لإعادة المحاولة؛ ولا يتغير المخزون أو بيانات المنتج أو حالة السلة. اختبار `tests/storefront-image-fallback.cjs`.
- **إصلاح مصدر بيانات المنتجات النافدة:** يقرأ الكتالوج الآن المنتجات المنشورة ذات المخزون صفر أيضاً (`stock=gte.0` بدلاً من `stock=gt.0`)، ويرفض المخزون السالب؛ وبذلك يمكن للواجهة عرض حالة النفاد بدلاً من اختفاء المنتج من المصدر. اختبار `tests/catalog.cjs` يغطي المنتج المتوفر والنافد دون أي تعديل في قاعدة البيانات.
- المنتجات النافدة تبقى قابلة للبحث والعرض، لكن زر إضافتها إلى السلة يكون معطّلاً مع رسالة عربية/إنجليزية واضحة، وتتحقق معالجة النقر كذلك من نفاد المخزون. يغطي `tests/storefront-search.cjs` العرض باللغتين. لا يجري حجز مخزون أو طلب حقيقي.
- السلة والمفضلة تجريبيتان ومحفوظتان محلياً في متصفح الجهاز، وإرسال الطلبات والدفع الإلكتروني غير مفعّلين.
- عند تلف بيانات السلة المحلية، يتجاهل المتجر القيم غير الصالحة ويحدّ الكمية بما يتوافق مع المخزون. إذا حظر المتصفح عمليات التخزين، تظل السلة والمفضلة تعملان مؤقتاً في الجلسة دون ضمان بقائهما بعد إغلاق الصفحة.
- **اتفقنا على تأجيل الدفع الإلكتروني**، فلا يُفعّل أي تحصيل في النسخ الأولية.
- أسعار الصرف المعروضة تقريبية لأغراض العرض فقط وليست أسعار سوق مباشرة؛ لا تستخدم للتحصيل.
- إعداد اللغة والعملات المحفوظ على جهاز الزائر يقبل فقط الخيارات المعروضة؛ عند فساد الإعدادات تعود اللغة إلى اختيار الجهاز والعملة إلى `SYP` بدلاً من إظهار أسعار غير رقمية. التحويلات المعروضة تجريبية.
- لا بد من إعداد حساب مدير بصلاحية `admin` من بيانات التطبيق الموثوقة في Supabase.
- **اكتمال جرد التاجر للقراءة فقط:** تجلب لوحة التاجر المنتجات بصفحات مرتبة ترتيباً ثابتاً (100 منتج لكل صفحة) حتى 1000 منتج، بدلاً من اعتبار أول استجابة من Supabase جرداً كاملاً. ترفض النتائج المكررة أو غير الصالحة أو تجاوز الحد ولا تعرض إحصاءات جزئية مضللة؛ وتتوقف عن عرض النتائج إذا تغيرت الجلسة أثناء التصفح. لا تتغير صلاحيات الكتابة أو قاعدة البيانات. اختبار `tests/seller-pagination.cjs`.
- **حالة صلاحيات التاجر في Supabase (5 نوفمبر 2026):** جداول `stores` و`products` لديها RLS وسياسات تحدد المالك والمسودات، لكن دور `authenticated` لديه `SELECT` على `products` ولا يملك `INSERT` على `stores` أو `products` ولا `UPDATE(stock)` على `products`. لذلك عُطلت أزرار التقديم والحفظ وتعديل المخزون في الواجهة بدلاً من الإيحاء أنها تعمل. لم نوسّع الصلاحيات؛ يلزم اعتماد منح أعمدة وعمليات محددة بعد مراجعة حماية قاعدة البيانات، ولا يعتمد التفعيل على فحص الواجهة وحده.
- لا تضع مفتاح `service_role` أو أي مفاتيح سرية في ملفات الواجهة أو GitHub.
- محمّل الكتالوج يقبل مفاتيح Supabase العامة `sb_publishable_` أو JWT قديم يحمل دور `anon` فقط، ويرفض مفاتيح JWT التي تحمل دوراً أعلى مثل `service_role`؛ هذا فحص وقائي في المتصفح وليس بديلاً عن سياسات RLS أو حماية الأسرار.
- لا تستخدم بيانات عملاء حقيقية للاختبار.

## متطلبات الإطلاق التجاري

1. إنشاء حساب إدارة موثّق وتحديد صلاحيات البائعين.
2. رفع منتجات حقيقية مع صور وأسعار ومخزون دقيق، واختبار ظهورها على الموقع.
3. إنشاء مسار آمن لإتمام الطلبات من الخادم مع التحقق من السعر والمخزون وعدم تكرار الطلبات.
4. اعتماد سياسة حجز وتحديث المخزون وإلغاء الطلبات والاسترجاع.
5. ربط مزود دفع مرخّص، وتفعيل تأكيد الدفع من الخادم عبر Webhook موثوق، وعدم اعتبار واجهة العميل إثباتاً للدفع.
6. توفير أسعار صرف معتمدة أو أسعار مستقلة لكل عملة، مع توضيح العملة السورية الجديدة دون استخدام سعر افتراضي للتحصيل.
7. مراجعة الأمان وسياسات RLS وCORS والصلاحيات وحماية البيانات الشخصية.
8. اختبار رحلة شراء كاملة على الهاتف بالعربية والإنجليزية، واختبار الفواتير والشحن والاسترجاع.
9. إعداد سياسات الخصوصية والشحن والاستبدال والإرجاع والضرائب حسب أسواق التشغيل.

- **إتاحة سلة المشتريات:** عند فتح السلة ينتقل تركيز لوحة المفاتيح إلى زر الإغلاق، وتبقى حركة Tab داخل النافذة، ويعيد زر Escape أو الإغلاق التركيز إلى العنصر السابق. تظهر حالة فتح السلة عبر `aria-expanded` وارتباط `aria-controls`. الطلبات والدفع غير مفعّلين.
- **التحكم بكميات السلة:** أزرار الزيادة والنقصان لها تسميات عربية/إنجليزية توضّح المنتج، ويستعيد زر الكمية التركيز بعد إعادة رسم السلة؛ إذا أُزيل آخر عنصر يعود التركيز إلى زر إغلاق السلة. يظل حد المخزون سارياً، ولا تُنشأ طلبات أو مدفوعات. اختبار الانحدار: `tests/cart-quantity-focus.cjs`.

- **تحديث الكتالوج:** عند بدء تحديث المنتجات أو الأقسام، تُخفى بطاقات المخزون القديمة ويُعطّل نسخ ملخص السلة حتى وصول نتيجة كاملة وصالحة. تبقى عناصر السلة محفوظة محلياً، ثم تُراجع كمياتها وفق المخزون الجديد. عند فشل التحديث تبقى البطاقات المخفية ولا تظهر معلومات قديمة على أنها حديثة. يغطي اختبار `tests/catalog-refresh-pending.cjs` فترة انتظار الاستجابة والنجاح والفشل.

### صفحات جرد التاجر (قراءة فقط)
تعرض لوحة التاجر 25 منتجاً في كل صفحة من الجرد المحمّل والمتحقق منه كاملاً، مع أزرار السابق/التالي وعدد الصفحات باللغتين العربية والإنجليزية. يعاد التصفح إلى الصفحة الأولى بعد تغيير البحث أو التصفية أو الترتيب أو تحديث الجرد. لا تؤثر صفحات العرض على إحصاءات المخزون أو تصدير CSV الشامل، ولا تُفعّل أي كتابة أو معاملات مالية. اختبار الانحدار: `tests/seller-display-pagination.cjs`.

- **سلامة تصدير CSV:** يحمي تصدير جرد التاجر من صيغ الجداول التي تبدأ بعلامات `=`, `+`, `-`, `@` حتى عند وجود محارف Unicode غير مرئية (مثل علامات اتجاه النص أو المسافة الصفرية) قبل العلامة؛ لا يغيّر هذا التعديل بيانات المخزون أو يفعّل أي كتابة. اختبار `tests/seller-inventory-export.cjs`.

- **معاينة مسودة المنتج محلياً:** يمكن للتاجر المعتمد معاينة الاسم والوصف والقسم والسعر والمخزون بالعربية أو الإنجليزية قبل الحفظ؛ لا تُرسل المعاينة أي طلب شبكة ولا تحفظ المنتج أو الصورة أو بيانات العميل، وتظل الكتابة إلى Supabase معطّلة. اختبار `tests/seller-draft-preview.cjs`.

- **إغلاق معاينة المسودة:** أُضيف زر «إخفاء المعاينة / Hide preview» لمسح المعاينة المحلية فوراً وإيقاف تحديثها عند تغيير الحقول، دون حفظ أو إرسال بيانات. يغطيه `tests/seller-draft-preview.cjs`.

- **معاينة صور مسودة المنتج:** تعرض لوحة التاجر صورة المنتج المختارة محلياً عبر عنوان مؤقت، مع تحرير العنوان المؤقت عند تغيير المدخلات أو إخفاء المعاينة أو الخروج أو إعادة تحميل الأقسام. إذا كان الملف غير مدعوم أو تجاوز 5 ميغابايت، تظهر رسالة واضحة بالعربية أو الإنجليزية بدلاً من تجاهل الصورة بصمت. لا يتم رفع الصور أو حفظ المسودة إلى قاعدة البيانات. يغطي الاختبار `tests/seller-draft-preview.cjs` هذا المسار.

- **تنزيل مسودة منتج بلا اتصال:** يمكن للتاجر تنزيل ملف JSON محلي يحتوي أسماء المنتج ووصفه بالعربية والإنجليزية والقسم والسعر بالدولار والمخزون بعد التحقق من المدخلات. لا يحتوي الملف صورة المنتج أو بيانات حساب أو عملاء، ولا يُرفع إلى الخادم أو يُنشئ منتجاً حقيقياً. اختبار `tests/seller-draft-export.cjs`.
